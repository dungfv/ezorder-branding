Selling in person creates the same paperwork as selling online. A customer picking up a click-and-collect order wants a packing slip. A wholesale buyer at your showroom needs a proper invoice with your tax number. A return at the counter calls for a refund note.

Shopify POS handles the payment and the standard sales receipt well. For branded, full-page documents that match what you send online, you need a document app that plugs into POS. This guide shows how to set that up with EZ Order Printer.

## What you can print from Shopify POS

With EZ Order Printer installed, the order screen in Shopify POS gets a **Print with EZ Order Printer** action. From there staff can print four documents for the open order:

- **Invoice / Receipt** — a full invoice with your logo, tax details, line items and totals.
- **Packing slip** — items and quantities without prices, ideal for pickups and gift orders.
- **Refund / Credit note** — the refunded lines and the amount returned to the customer.
- **Return slip** — the returned items and your return instructions.

Every document uses the same templates, branding and language settings as your online orders, so a customer gets an identical invoice whether they bought on your website or in your store.

## Before you start: printer and device setup

Branded documents are full-page (A4 or Letter), so they print through the device's standard print dialog rather than through a narrow thermal receipt printer.

- **iPad and iPhone:** use a printer that supports AirPrint on the same Wi-Fi network as the POS device.
- **Android:** use a printer supported by the device's print service (most networked office printers work with the default Android print service or the manufacturer's plugin).
- **Thermal receipt printers** remain perfect for Shopify's native sales receipts; keep them for that job and add a small laser or inkjet printer for full-page documents.

Print a test page from the device's system settings first. If the device can see the printer there, it will see it from Shopify POS.

## Step-by-step: printing a packing slip or receipt in Shopify POS

### 1. Install EZ Order Printer and set up your templates

Install the app from the Shopify App Store and configure your templates in Shopify admin — logo, colours, company details and the blocks you want to show. POS uses these templates automatically; there's nothing extra to design.

### 2. Make sure staff have access to the app

Printing from POS runs as the signed-in user. If a staff member sees *"You do not have permission to print from this app"*, ask the store owner to give that user access to EZ Order Printer in the Shopify admin's user permissions.

### 3. Open the order in Shopify POS

Go to **Orders**, find the order — by number, customer name or by scanning the order barcode — and open the order details.

### 4. Tap "Print with EZ Order Printer"

Open the order's action menu and choose **Print with EZ Order Printer**. A panel lists the available documents.

### 5. Choose the document and print

Tap **Invoice / Receipt**, **Packing slip**, **Refund / Credit note** or **Return slip**. The system print dialog opens; pick your printer and print. The document is always generated from the latest order data, so edits and refunds made moments ago are included.

## Common use cases in a physical store

- **Click-and-collect pickups:** print the packing slip, pack the order, staple the slip to the bag.
- **B2B and trade customers:** hand over a full invoice with purchase-order number and tax ID at the counter.
- **Returns and exchanges:** process the refund in POS, then print a credit note for the customer's records.
- **Gift purchases:** print a packing slip without prices to include in the gift bag.

## Troubleshooting

### The print action doesn't appear in POS

Make sure the app is installed and that you are on the order details screen (the action lives in the order's action menu). Update the Shopify POS app to the latest version if you've just installed EZ Order Printer.

### "You do not have permission to print from this app"

The signed-in user doesn't have access to the app. The store owner can grant it in the Shopify admin under user permissions.

### The printer doesn't show up

Confirm the POS device and the printer are on the same network and that the printer appears in the device's own print settings. Restarting the printer usually re-announces it on the network.

### The document looks different from the preview

The POS print uses the same template as the admin. If something looks off, open the template in Shopify admin, preview the same order, and adjust there — changes apply to POS immediately.
